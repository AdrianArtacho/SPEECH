SPEECH URL Helper

Write your cards directly into a shareable link, or connect a published spreadsheet.

Use one text box per card. Markdown, line breaks, and special characters are supported.
Anyone with the link can read the cards. Editing the text creates a new link; links you have already shared keep their original text.
In Google Sheets → File → Share → Publish to web → CSV. Cards come from the first column.

This link is long and may be shortened or rejected by some apps. For a longer speech, consider using a published CSV instead.
