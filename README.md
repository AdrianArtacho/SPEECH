# Text Cards

A minimal full-screen friendly [“text card” viewer](https://adrianartacho.github.io/SPEECH/) that loads its content directly from a shareable speech link or from a CSV URL.

---

## 🛟Helper

Use the [helper page](https://adrianartacho.github.io/SPEECH/helper.html) to create a shareable link:

- **Direct text:** enter one card per text box and use **Add card** for the next one. Each card supports Markdown, multiple paragraphs, accents, and emoji. The generated link contains all the cards; no spreadsheet or separate data hosting is needed.
- **CSV URL:** paste a public CSV URL, such as a Google Sheets sheet published to the web as CSV.

Both modes support an optional title and starting card, with **Copy**, **Share**, and **Open** buttons. To edit an existing speech link, use **Edit** in the viewer. The helper restores the cards and options.

Speech links contain a fixed snapshot: editing the cards creates a new link. Anyone with the link can read its contents. Very long links may be truncated by sharing apps or rejected by browsers/servers; the helper flags links over 8,000 characters. CSV remains useful for longer speeches and content you want to update without changing the link.

## Usage

### Direct speech data

Use `?speech=<ENCODED_SPEECH>`, generated by the helper. For example, [open two cards: “Hello” and “World”](https://adrianartacho.github.io/SPEECH/?speech=v1.WyJIZWxsbyIsIldvcmxkIl0&title=Example).

The format is `v1.` followed by the unpadded, URL-safe Base64 encoding of a UTF-8 JSON array of non-empty strings. Each string is one card; line breaks and Markdown are preserved. Encoding is not encryption.

For scripts or integrations, load [`speech-data.js`](./speech-data.js) and use:

```js
const url = new URL("https://adrianartacho.github.io/SPEECH/");
url.searchParams.set("speech", SpeechData.encode([
  "# Welcome 👋\n\nFirst card.",
  "Second card with **emphasis**."
]));
url.searchParams.set("title", "My speech");
// url.toString() is ready to share; no extra encodeURIComponent is needed.
```

`SpeechData.decode(value)` returns the card array. If both `speech` and `csv` are supplied, `speech` takes precedence. Invalid or incomplete speech data displays an error instead of falling back to CSV.

### CSV data

Open your GitHub Pages URL like:

- `...?csv=`[<ENCODED_CSV_URL>](https://adrianartacho.github.io/UrlEncode/)
- Optional: `&title=Musikproduktion`
- Optional: `&i=2` to start on card 2 (works with either input mode)

Example (Google Sheets published CSV):

`?csv=https%3A%2F%2Fdocs.google.com%2Fspreadsheets%2Fd%2Fe%2F2PACX-1vTZgGV7UM0gkQz7GdeIGV_Gq3uzTpUnW3dbWXew4S_X2Ls3ngc8oB3pvrywhIHm3ge6oRRlHHmbnZwP%2Fpub%3Fgid%3D0%26single%3Dtrue%26output%3Dcsv&title=Example`

## CSV format

Each row becomes one card. The **first column (A)** is used as the card text.

Markdown is supported (headings, lists, links, inline code, etc.). Emoji works as usual.

## Controls

- Swipe left/right (mobile)
- Tap anywhere (go next)
- Buttons ◀ ▶
- Keyboard: ←/→, PageUp/PageDown, Space (next)
- Fullscreen button ⛶ (or press `f`)

## Looping

When you reach the last card, it wraps to the first automatically.

## GitHub Pages setup

1. Keep `index.html`, `helper.html`, and `speech-data.js` at the repo root
2. Settings → Pages → Deploy from branch → `main` / root

Embedded speech data does not require a Google account or a CSV fetch. The viewer still loads its Markdown renderer and sanitizer from a CDN, so this does not provide offline viewing.
